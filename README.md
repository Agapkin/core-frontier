# CORE FRONTIER

Прототип модульной стратегии с элементами:

- tower defense
- автоматизации
- добычи ресурсов
- производственных цепочек
- развития технологий
- выживания базы

## Концепция

Игрок начинает с небольшой базы.

Добывает:
- дерево
- камень
- еду
- металлы
- энергию

Строит:
- башни
- производство
- конвейеры
- защиту
- исследовательские здания

Отбивается от волн врагов и постепенно открывает новые эпохи и технологии.

## Главная идея проекта

Создать универсальное игровое ядро, которое позволит:

- быстро создавать новые игровые режимы
- менять визуальный стиль
- добавлять новые ресурсы
- подключать новые механики
- создавать отдельные игры на базе одного движка
