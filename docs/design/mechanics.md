# CORE FRONTIER — GAME MECHANICS

## Текущее состояние проекта

CORE FRONTIER развивается как гибрид:

~~~text
RTS + Tower Defense + Recovery Economy + Persistent Defense
~~~

Проект больше не является просто wave-defense.

Главная идея:
игрок не только отбивает волны,
но и:
- строит инфраструктуру;
- управляет энергией;
- восстанавливается после атак;
- перерабатывает последствия боёв;
- постепенно расширяет фронтир.

---

# 5. Энергия

## Реализовано

Каждая башня потребляет энергию.

Игрок ограничен:
- power capacity;
- количеством активных башен.

Это предотвращает:
- бесконечный spam башен;
- мгновенное застраивание карты.

---

## Планируется

### Генераторы

Постройки для увеличения лимита энергии.

### Энергосеть

Передача питания между зданиями.

### Уязвимость инфраструктуры

Враги смогут разрушать энергосистему.

---

# 6. Retry Wave

## Реализовано

Перед запуском волны создаётся checkpoint.

При поражении:
- игрок может повторить волну;
- откатываются ресурсы;
- откатываются башни;
- откатывается HP базы;
- откатывается состояние карты.

### Цель механики

Избежать:
- бессмысленного полного restart;
- потери длинного прогресса.

---

# 7. Full Restart

## Реализовано

Полный сброс игры.

Используется только через меню.

### Назначение

Новая игровая сессия с нуля.

# 8. Game Over

## Реализовано

Когда HP базы падает до нуля:
- игра останавливается;
- появляется overlay поражения;
- открывается Retry Wave;
- доступна новая игра.

# Planned Mechanics — Следующий этап

### Идея

- обломки;

- биомасса;

Игрок:
- собирает остатки;
- перерабатывает их;
- восстанавливает инфраструктуру;
- готовится к следующей волне.

---

## 2. Salvage System

### Планируется

После уничтожения:
- башен;
- врагов;
- зданий;

на карте остаются salvage objects.

### Их свойства

- занимают место;
- блокируют строительство;
- могут быть собраны;
- могут быть переработаны;
- дают ресурсы.

---

## 3. Harvester Units

### Планируется

Гражданские юниты:
- собирают salvage;
- вывозят ресурсы;
- работают между волнами;
- автоматически патрулируют карту.
