## 1. Назначение документа

Этот файл является evolving repository cognition discovery layer для CORE FRONTIER.

Он хранит:

- verification findings;
- header/code cross-verification findings;
- mixed-responsibility observations;
- extraction-origin observations;
- synchronization sensitivity findings;
- uncertainty markers;
- candidate field evolution.

Этот файл intentionally:

- experimental;
- append-oriented;
- continuation-friendly;
- uncertainty-aware;
- non-authoritative.

Repository truth remains:

- actual code;
- actual runtime behavior.

Headers remain interpretation layer only.

If header and code diverge:

code wins.
