4. Debt Classification Model
━━━━━━━━━━━━━━━━━━━━

Debt states used in this document:

currently_stabilized:
pressure no longer dominates current operational instability,
but still requires future monitoring.

partially_stabilized:
pressure became bounded and clarified,
but not finalized.

active_unresolved:
pressure currently survives
and still requires bounded future stabilization.

intentionally_deferred:
pressure is intentionally postponed
because prerequisite stabilization does not yet exist.

future_index_pressure:
pressure appears connected to future Index Era preparation,
but must NOT be interpreted as implementation authorization.

repository_consistency_gap:
cross-layer inconsistency currently exists between Repository Map artifacts.

obsolete_or_transformed:
earlier pressure changed meaning,
migrated
or no longer exists in original form.
