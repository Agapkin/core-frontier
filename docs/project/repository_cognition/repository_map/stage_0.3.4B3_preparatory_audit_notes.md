3. Что такое Repository Map
━━━━━━━━━━━━━━━━━━━━

Repository Map —
это не “вторая архитектура”.

И не “вторая игра”.

Repository Map —
это навигационная система,
которая помогает:

* понимать runtime;
* видеть связи gameplay-систем;
* безопаснее менять код через GPT;
* постепенно разделять монолитные файлы.

Игрок ставит tower.

Чтобы это сработало,
runtime должен:

* проверить клетку;
* проверить ресурсы;
* создать объект;
* обновить rendering;
* обновить HUD.

Repository Map
пытается объяснить:
как эти части связаны.
