# Stage 02.2 — Stabilization и подготовка к расширению

## Цель

Стабилизировать текущую grid-based архитектуру перед добавлением новых игровых систем.

На предыдущих этапах были реализованы:
- карта
- камера
- сетка
- маршрут врагов
- строительство башен
- базовый UX строительства

Теперь необходимо устранить архитектурные и gameplay-проблемы, выявленные во время тестирования.

---

## Основные задачи

### 1. Исправление строительства на дороге

Текущая проверка маршрута работает только частично.

Нужно:
- запретить строительство на всей ширине дороги
- учитывать все клетки маршрута
- корректно определять горизонтальные и вертикальные участки пути

---

### 2. Стабилизация системы волн

Необходимо:
- улучшить контроль состояния waveActive
- подготовить систему wave manager
- добавить основу для future wave scaling
- подготовить поддержку разных типов врагов

---

### 3. Подготовка к системе типов башен

Текущая версия содержит только одну башню.

Нужно подготовить архитектуру под:
- разные типы башен
- разные стоимости
- разные характеристики
- разные роли башен

Пока без полноценной реализации.

---

### 4. Подготовка к системе типов врагов

Сейчас враги однотипные.

Необходимо подготовить основу под:
- разные HP
- разные скорости
- разные награды
- разные роли
- разный внешний вид

На раннем этапе допускается использование:
- кругов
- квадратов
- треугольников

---

### 5. Подготовка к разделению game.js

Текущий game.js постепенно становится слишком большим.

Нужно подготовить архитектуру к будущему разделению:
- camera
- enemies
- towers
- map
- ui
- waves

На этом этапе само разделение еще не выполняется.

---

### 6. Подготовка data-driven архитектуры

Необходимо начать продумывать:
- JSON-конфиги
- хранение параметров врагов
- хранение параметров башен
- хранение ресурсов
- wave presets

Пока без полноценного подключения JSON.

---

## Что пока НЕ делаем

На данном этапе не добавляются:

- экономика
- добыча ресурсов
- рабочие
- производство
- conveyor systems
- multiplayer
- AI цивилизации
- zoom камеры
- полноценные изображения

---

## Ожидаемый результат

После Stage 02.2 проект должен получить:

- стабильную систему строительства
- корректную проверку дороги
- фундамент для разных типов башен
- фундамент для разных типов врагов
- подготовку к разделению game.js
- подготовку к data-driven архитектуре

---

## Архитектурный вывод

Stage 02.2 является переходным этапом между:
- prototype architecture
и
- expandable engine architecture

Основная задача этапа — стабилизировать фундамент перед масштабированием игровых систем.
