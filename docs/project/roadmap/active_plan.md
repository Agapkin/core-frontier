- bounded workflow stabilization;
- contract visibility stabilization.

- repo-wide rewrites;
- uncontrolled passes;
- giant connector operations.

## Safe runtime evolution model

Будущие runtime passes должны быть:

- bounded;
- isolated;
- compatibility-safe;
- inspection-driven;
- dependency-aware.

Особенно осторожно:

- build flow;
- systems.js;
- game.js;
- input/camera logic;
- restart/retry lifecycle;
- render/update order;
- mobile interaction zones.
