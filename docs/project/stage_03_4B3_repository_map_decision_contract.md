4. Runtime/source остаётся главным источником правды
━━━━━━━━━━━━━━━━━━━━

Repository Map:

* НЕ заменяет код;
* НЕ является второй архитектурой;
* НЕ является исполняемой системой.

Главный источник правды:

* runtime-код;
* source files;
* фактическое состояние репозитория.

Discovery:

* остаётся актуальным аудитом;
* хранит происхождение выводов;
* помогает понимать,
    почему проблема была обнаружена.

Но активные выводы
должны подтверждаться:

* runtime/source;
* direct repository verification.
