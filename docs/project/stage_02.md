# Stage 02 — Карта, камера и строительство по клеткам

## Цель
Превратить текущий прототип из хаотичного поля в первую карту с управляемым пространством.

## Планируется реализовать
- большая карта больше размера экрана
- перемещение камеры пальцем или мышью
- сетка клеток
- строительство башен по выбранной клетке
- путь врагов к базе
- ограничение запуска новой волны, пока текущая не завершена
- увеличение скорости врагов до комфортного темпа

## Текущая проблема
В версии Stage 01 башни появляются случайно, враги идут хаотично, а игрок не управляет пространством карты.

## Ожидаемый результат
Игрок сможет перемещаться по карте, выбирать место строительства башни и запускать волны, которые идут по заданному маршруту к базе.
