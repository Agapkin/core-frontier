# Stage 02 — Карта, камера и строительство по клеткам

## Цель
Превратить текущий прототип из хаотичного поля в первую карту с управляемым пространством.

## Планируется реализовать
- большая карта больше размера экрана
- перемещение камеры пальцем или мышью
- сетка клеток
- строительство башен по выбранной клетке
- путь врагов к базе
- ограничение запуска новой волны, пока текущая не завершена
- увеличение скорости врагов до комфортного темпа

## Текущая проблема
В версии Stage 01 башни появляются случайно, враги идут хаотично, а игрок не управляет пространством карты.

## Ожидаемый результат
Игрок сможет перемещаться по карте, выбирать место строительства башни и запускать волны, которые идут по заданному маршруту к базе.

## Тестирование

Проверено:
- карта отображается корректно
- камера перемещается
- сетка клеток отображается
- враги движутся по маршруту
- здоровье врагов отображается
- база получает урон при достижении врага
- новая волна не запускается до завершения текущей

## Проблемы текущей версии

- строительство башен работает нестабильно на touch-устройствах
- отсутствует подсветка выбранной клетки
- отсутствует preview башни перед установкой
- отсутствует масштабирование камеры
- отсутствует визуальный feedback доступности клетки

## Выводы

Базовая система карты и маршрутов работает корректно.

Проект перешёл от хаотичного canvas-прототипа к полноценной grid-based архитектуре, пригодной для дальнейшего расширения механик.
