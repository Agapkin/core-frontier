# Stage 02.4.3 — Modularization / Разделение game.js на модули

## Цель этапа

Разделить текущий монолитный файл `js/game.js` на несколько крупных логических модулей, не меняя игровое поведение.

Stage 02.4.2 показал, что проект уже стал слишком большим для одного файла.

Текущий `game.js` содержит:
- данные игры,
- состояние игры,
- игровые системы,
- UI,
- отрисовку,
- управление,
- camera / zoom,
- Retry Wave,
- Codex,
- строительство,
- волны,
- башни,
- врагов.

Это усложняет:
- поддержку,
- генерацию кода через GPT,
- поиск ошибок,
- дальнейшее расширение игры.

---

# Главный принцип

На этом этапе НЕ добавляем новые игровые механики.

Задача Stage 02.4.3:

разрезать код на модули так, чтобы игра после разрезки работала так же, как до разрезки.

---

# Планируемая структура JS

После разрезки папка `js/` должна выглядеть так:

```text
js/
├── data.js
├── state.js
├── systems.js
├── ui.js
└── game.js
```

---

# Назначение файлов

## data.js

Источник истины по игровым данным.

Содержит:
- `TILE_SIZE`
- `map`
- `difficultyProfiles`
- `gameBalance`
- `towerTypes`
- `enemyTypes`
- `enemyPath`
- `roadTiles`

Правило:

Все характеристики башен, врагов, сложности, экономики и карты должны храниться здесь.

Нельзя дублировать эти данные в UI, Codex или боевой логике.

---

## state.js

Состояние текущей игровой сессии.

Содержит:
- `camera`
- `uiState`
- `resources`
- `base`
- `power`
- `waveState`
- `gameState`
- `checkpoint`
- `gameSpeed`
- `towers`
- `enemies`

Также содержит базовые helper-функции состояния:
- `clone`
- `updatePower`

---

## systems.js

Игровая логика.

Содержит:
- строительство
- продажу башен
- проверку клеток
- волны
- spawn врагов
- update врагов
- update башен
- награды
- Retry Wave
- Full Restart
- Game Over

Это файл, где меняется логика игры.

---

## ui.js

Интерфейс и отрисовка.

Содержит:
- создание кнопок
- HUD
- меню
- Codex
- уведомления
- панели
- draw-функции
- notification layer

Это файл, где меняется визуальное отображение и UI.

---

## game.js

Главная точка запуска.

Содержит:
- получение canvas
- resize
- input handlers
- zoom / camera input
- запуск UI
- запуск game loop

Этот файл должен стать максимально маленьким.

---

# Изменения в index.html

Сейчас подключается:

```html
<script src="js/game.js"></script>
```

После разрезки нужно подключать файлы по порядку:

```html
<script src="js/data.js"></script>
<script src="js/state.js"></script>
<script src="js/systems.js"></script>
<script src="js/ui.js"></script>
<script src="js/game.js"></script>
```

Порядок важен.

---

# Правило источника истины

Главное правило модульности:

## Данные не дублируются

Например:

- Codex берёт данные из `towerTypes` и `enemyTypes`.
- Строительство берёт стоимость башни из `towerTypes`.
- Баланс волн берёт данные из `difficultyProfiles` и `gameBalance`.
- UI отображает энергию из `power`.
- Retry Wave сохраняет состояние из `state.js`.

Если нужно изменить башню, меняется только `data.js`.

Если нужно изменить врага, меняется только `data.js`.

Если нужно изменить отображение, меняется `ui.js`.

Если нужно изменить механику, меняется `systems.js`.

# План тестирования Stage 02.4.3

## Цель тестирования

Проверить, что после разделения `game.js` на модули игра работает так же, как до разрезки.

Stage 02.4.3 не должен добавлять новые механики.  
Главная задача теста — убедиться, что модульность не сломала существующий gameplay Stage 02.4.2.

---

## Что нужно проверить

### 1. Запуск игры

Проверить:
- игра открывается через GitHub Pages;
- canvas отображается;
- верхний HUD отображается;
- нижняя панель отображается;
- нет визуально пустого экрана;
- нет зависания после загрузки.

---

### 2. Подключение модулей

Проверить, что после разделения работают:

- `data.js`
- `state.js`
- `systems.js`
- `ui.js`
- `game.js`

Если игра не запускается, вероятная причина:
- неправильный порядок подключения файлов в `index.html`;
- ошибка в одном из модулей;
- функция переехала, но ссылка на неё осталась в другом файле.

---

### 3. Карта и камера

Проверить:
- карта отображается;
- дорога отображается;
- база отображается;
- drag камеры работает;
- zoom кнопками работает;
- pinch zoom работает;
- камера не уходит за пределы карты;
- проценты zoom обновляются в HUD.

---

### 4. Строительство

Проверить:
- кнопка "Башня" включает режим строительства;
- клетка выбирается;
- появляется подтверждение строительства;
- кнопка "Построить" работает;
- кнопка "Отмена" работает;
- башня строится на свободной клетке;
- нельзя строить на дороге;
- нельзя строить на базе;
- нельзя строить поверх другой башни;
- при нехватке энергии появляется уведомление.

---

### 5. Башни

Проверить:
- башня выбирается тапом;
- отображается радиус башни;
- отображается панель башни;
- продажа башни работает;
- ресурсы возвращаются;
- энергия освобождается;
- кнопка улучшения показывает, что нужна технология.

---

### 6. Волны

Проверить:
- волна запускается;
- враги появляются;
- враги идут по дороге;
- враги имеют HP bar;
- башни стреляют;
- враги получают урон;
- за убийство врагов начисляется дерево;
- при достижении базы HP базы уменьшается;
- волна завершается корректно.

---

### 7. Скорость игры

Проверить:
- x1 работает;
- x2 работает;
- x3 работает;
- враги реально ускоряются;
- UI не ломается при смене скорости.

---

### 8. Retry Wave

Проверить:
- перед волной создаётся checkpoint;
- при поражении появляется окно Game Over;
- кнопка "Повторить волну" работает;
- состояние откатывается к подготовке перед проигранной волной;
- восстанавливаются ресурсы;
- восстанавливаются башни;
- восстанавливается HP базы;
- восстанавливается номер волны;
- очищаются враги.

---

### 9. Новая игра

Проверить:
- кнопка "Новая игра" полностью сбрасывает прогресс;
- очищаются башни;
- очищаются враги;
- сбрасываются ресурсы;
- сбрасывается HP базы;
- сбрасывается номер волны;
- сбрасывается zoom и положение камеры.

---

### 10. Codex / Справка

Проверить:
- Codex открывается;
- отображаются башни;
- отображаются враги;
- отображаются характеристики;
- отображаются механики;
- данные совпадают с тем, что реально используется в игре.

Важно:
Codex должен брать данные из `data.js`, а не иметь отдельные вручную продублированные значения.

---

### 11. Сложность

Проверить:
- меню сложности открывается;
- сложность можно выбрать до первой волны;
- после старта игры сложность менять нельзя;
- выбранная сложность отображается в HUD.

---
