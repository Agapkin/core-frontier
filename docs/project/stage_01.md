# Stage 01 — Первый прототип

## Цель
Создать первый рабочий цикл игры.

## Реализовано
- создан GitHub репозиторий
- подключён GitHub Pages
- создан canvas
- реализованы башни
- реализованы враги
- реализованы волны
- реализована стрельба
- добавлены ресурсы
- добавлено здоровье базы

## Выводы
- базовая архитектура работает
- GitHub Pages подходит для быстрого тестирования
- необходима система карты и камеры
## Тестирование

Проверено:
- проект открывается через GitHub Pages
- CSS и JS подключаются корректно
- кнопка строительства башни работает
- кнопка запуска волны работает
- башни стреляют по врагам
- ресурсы списываются
- HP базы отображается

## Ограничения текущей версии

- волны можно запускать бесконечно
- враги двигаются слишком медленно
- башни появляются случайно
- нет карты
- нет сетки
- нет перемещения камеры
- нет маршрута врагов
